# Interactive Anniversary Website — Portfolio Demo

I built an interactive anniversary website using HTML, CSS, and JavaScript. I wanted it to look like a cozy retro computer, with different pages to explore instead of a regular scrolling website.

This repository is a **privacy-safe portfolio demo**. I've replaced the original personal photos, messages, and quiz questions with sample content.

## Features

- Retro desktop/window design
- Navigation between different screens
- Story timeline and gallery layouts
- Clickable notes
- Interactive quiz with score tracking
- Responsive styling

## Files

- `index.html` — page layout
- `style.css` — design and styling
- `script.js` — navigation, gallery interactions, notes, and quiz

To view the demo, download the files and open `index.html` in a browser.

The original personal version isn't included here. All photos, questions, and messages in this demo are placeholders.
